# Security & responsible disclosure

LEAD LEAKAGE AUDITOR is presented publicly as an **offline-first prototype**. This repository contains a **static product description and a synthetic SVG screenshot**, not client records, source code, a live CRM integration, a checkout form or a functioning production environment.

**Public GitHub Issues are publicly readable.** Do not paste real CRM exports, customer names/addresses, credentials, payment details, confidential terms, API tokens or vulnerabilities with exploitation details into an Issue.

Report potential security problems privately to **agenticcommerce975@gmail.com** (subject: "Lead Leakage Auditor — security report"). Include an initial high-level description only and do not send sensitive customer data by unprotected email.

The offline prototype does not guarantee 100% data security; workstation security, browser extensions, local file storage, client authorization and applicable privacy rules remain relevant. No independent penetration-test certification, SLA or bug bounty is represented by these materials.
