## How we approach B2B engagements

**01 · Define the problem** — available systems, workflow, constraints, and desired outcome.

**02 · Check feasibility** — evaluate existing solutions first; identify data and access requirements.

**03 · Demonstrate and verify** — scoped test with synthetic or properly authorized data; write down acceptance criteria and false positives.

**04 · Agree scope** — deliverables, limits, commercial terms and responsibilities are negotiated separately. No production readiness or financial result is implied by a public demo.
