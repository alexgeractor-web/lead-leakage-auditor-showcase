## Intended buyer

Film/video production agencies, independent production companies and web-development agencies that routinely launch studio sites and need a reusable, specialized foundation. The likely benefit is reducing custom work on film/people/press/festival content structures, **subject to the buyer's own estimate of engineering effort and deployment costs**.

## What has actually been implemented

- A public, synthetic **browser-only** interactive white-label preview (not the commercial source or hosted CMS).
- A **separate private runnable** JavaScript/Node.js single-installation starter. Fictional tenant records generate static film, people, journal, festival and press pages.
- A password-protected **localhost-only Studio Desk** that edits fictional tenant data and rebuilds static pages with revision conflict protection.
- Authenticated local JSON backup and a manual review-before-publish restore workflow.
- Reproducible source release export with a file manifest and SHA-256 checksums.
- Additional code-level Netlify Functions / Supabase-oriented editorial and media infrastructure exists in the original **branded studio implementation**, but its cloud production capabilities do **not** automatically transfer into, or operate inside, the standalone white-label starter.

## Proposed acquisition process

1. Buyer explains intended use, implementation team, deal structure and budget.
2. Seller provides a public fictional preview and a scoped non-confidential technical walkthrough.
3. Under appropriate confidentiality terms, parties review the exact transfer inventory, dependencies and technical acceptance tests.
4. Legal review validates chain of title and explicit **Schedule A** transferable software vs **Schedule B** excluded studio/creative rights.
5. Parties agree price, source handover, migration, correction period and any optional support in a definitive signed agreement.
6. Payment/escrow and final handover occur only as agreed. No automatic repo or credentials transfer.
